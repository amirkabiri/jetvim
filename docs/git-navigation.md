# Git pane navigation

Press `⌘9` to open Local Changes. Select a file with ↑/↓, then press → to focus
its diff on the right. The selected file and pane sizes stay unchanged while the
diff loads. Enter opens the source file instead.
Returning to an already loaded diff preserves its reading position.

Tab also focuses the diff; Shift-Tab returns to the changes list. Inside the diff,
arrow keys navigate its text. Right on a heading or empty changes list does
nothing.
